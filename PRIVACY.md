# Privacy policy

This document covers the **Memex MCP server** (Python package `memex-mcp`) and the **Memex Live Capture** Chrome extension.

Version: 0.1.0 (alpha). Last updated: 2026-05-25.

## What we collect

**Nothing leaves your machine.** Memex is a local-first tool. The Chrome extension talks only to `127.0.0.1:5777`, the address of the Memex server running on the same computer. The Memex server stores its index in a local SQLite file (default `./data/memex.db`).

We do not run any backend, telemetry endpoint, analytics service, or cloud component. There is no account, no login, no remote sync.

## What gets stored locally

The Memex server stores, on your own machine and only there:

- The text of your Claude.ai conversations (titles, messages, timestamps) as parsed from the official export or captured live by the extension.
- Vector embeddings of that text, generated locally by `fastembed` (default) or by your local Ollama instance.
- Optional auto-summaries generated by Claude Haiku, only if you opt-in via `MEMEX_SUMMARY_ENABLED=true` and provide your own `ANTHROPIC_API_KEY`. When enabled, the summary call goes from your machine directly to Anthropic's API using your key. Memex never proxies or sees that call.

The Chrome extension stores in `chrome.storage.local`:

- The configured server URL (default `http://127.0.0.1:5777`).
- Aggregated counters (number of chats ingested, number of failures, timestamp of the last ingest).
- A short list of recent error messages (truncated to 200 chars each).

The Chrome extension does NOT cache the content of your chats. It forwards each captured payload to the local Memex server and forgets it.

## What the extension's permissions are for

| Permission | Purpose |
|---|---|
| `storage` | Save the configured server URL and aggregated stats described above. |
| `https://claude.ai/*` | Read the chat data your browser already receives from Claude.ai so it can be indexed locally. |
| `http://127.0.0.1:5777/*` and `http://localhost:5777/*` | Forward captured chats to the local Memex server. |

The extension's `inject.js` runs in the MAIN world of `claude.ai` only to intercept the fetch responses for `chat_conversations/{id}?tree=True` (the same data the Claude.ai UI renders). It does not modify the page or interact with any other site.

## Third parties

There are no third-party services involved by default. The only opt-in third party is **Anthropic** (the Claude API), used **only** when you enable summaries and provide your own API key. Anthropic's own privacy policy applies to those calls. See https://www.anthropic.com/legal/privacy.

## Security

- The local HTTP server listens on `127.0.0.1` only. It is not reachable from the network.
- The server's origin check rejects any request that does not come from a browser extension (`chrome-extension://` or `moz-extension://` origin).
- The extension's host permissions are limited to `claude.ai` and `localhost:5777`.

## Your data, your control

Memex is open source ([MIT license](https://github.com/dioniipereyraa/memex/blob/main/LICENSE)). The local DB file is yours to back up, inspect, or delete at any time. Removing it wipes the index. Uninstalling the extension wipes the small stats blob stored by the browser.
